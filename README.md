# Superknova — Space-Themed Study Platform

## About the Project

Superknova is a space-themed, gamified study platform designed to make learning more engaging and productive. It combines quiz-based challenges, a space exploration board, a study timer, and progress tracking to encourage consistent study habits.

Users advance through the space-themed board by answering questions of varying difficulty. Correct answers move the rocket forward, while incorrect answers can move it backwards, making learning interactive and rewarding.

## Features

- **Space-Themed Game Board:** Explore a board inspired by space and rocket missions.
- **Quiz-Based Learning:** Answer questions across different difficulty levels.
- **Gamified Progression:** Advance or move backwards based on quiz performance.
- **Study Timer:** Manage focused study sessions.
- **Progress Statistics:** Track study progress and performance.
- **Interactive User Interface:** Navigate the platform through a dedicated web interface.

## Technologies Used

- **Python** — Core application logic and backend functionality.

## Getting Started

### Prerequisites

Ensure Python 3 is installed on your system.

### Installation

1. Clone or download the project repository.
2. Open the project folder in your terminal.
3. Install Flask:

   ```bash
   pip install flask
   ```

### Running the Application

Run the following command from the project directory:

```bash
python app.py
```

Open the local URL displayed in the terminal in your web browser. For a typical Flask application, this is:

```text
http://127.0.0.1:5000/
```

## How to Play

1. Open Superknova in your browser.
2. Start a study game or quiz challenge.
3. Answer questions based on their difficulty.
4. Move your rocket forward for correct answers and backwards for incorrect answers.
5. Use the study timer to organise focused learning sessions.
6. Review your progress and statistics.

## Project Objective

The primary objective of Superknova is to combine education and gamification to create a motivating study environment. By transforming learning into a space exploration experience, the platform aims to encourage active recall, improve engagement, and help students develop consistent study routines.
